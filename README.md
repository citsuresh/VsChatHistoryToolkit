# VsChatHistoryToolkit

Read-only search over Visual Studio Copilot Chat history stored on your machine, plus safe session renaming. A .NET library and `chathistory` CLI with capped JSON output, built for Copilot skills.

> **Coverage: `session-store.db` only.** Every result says so (`"coverage": "session-store.db only"`). The Visual Studio chat pane can list more chats than the database holds; this toolkit cannot see those.

## What it reads

`%LOCALAPPDATA%\Microsoft\VisualStudio\CopilotCli\`

- `session-store.db` (SQLite, WAL, schema version 8): sessions, turns, checkpoints, and the `search_index` FTS5 table.
- `session-state\<session-id>\workspace.yaml` (chat title) and `events.jsonl` (solution name).

Reads open the database with `mode=ro` plus `PRAGMA query_only=ON`, so they work while Visual Studio is running and still see rows that are only in the WAL. The database is never copied and never opened `immutable`. If the schema version (the `schema_version` table) is not 8, every command stops with an error naming the version found.

`rename` and `undo-rename` are the only commands that write, and only for one session (exact id): the `name:` and `user_named:` lines of its `workspace.yaml`, and its `sessions.summary`.

## Build and test

Requires the .NET 8 runtime (SDK 8 or newer to build). Open `VsChatHistoryToolkit.slnx` in Visual Studio 2022 17.13+ or run:

```
dotnet build
dotnet test
dotnet run --project src/VsChatHistoryToolkit.Cli -- sessions --text
```

Tests use only synthetic databases and session folders generated by the test code. No real chat data is used or stored.

`nuget.config` restricts restore to nuget.org.

## Commands

JSON by default, `--text` for humans. Full contract: [docs/CLI_CONTRACT.md](docs/CLI_CONTRACT.md).

```
chathistory search <terms...> [--limit N]
chathistory sessions [--repo S] [--cwd S] [--branch S] [--from DATE] [--to DATE] [--limit N]
chathistory show <id>
chathistory turns <id> [--index I | --range A-B] [--max-chars N]
chathistory checkpoints <id> [--full]
chathistory stats
chathistory rename <id> "<title>" [--force] [--dry-run]
chathistory undo-rename <id> [--force] [--dry-run]
```

A renamed title appears only after Visual Studio restarts.
